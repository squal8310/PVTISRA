# 🛒 PVTISRA — Sistema de Punto de Venta

> Sistema web de gestión comercial diseñado para agilizar y controlar las operaciones de venta de un negocio, desde el registro de productos hasta la generación de transacciones y seguimiento de ventas.

---

## 📋 ¿Qué es PVTISRA?

PVTISRA es un sistema de punto de venta (POS) accesible desde el navegador web. Permite a los operadores de un negocio gestionar su catálogo de productos, registrar ventas, controlar clientes y llevar un seguimiento de las operaciones comerciales del día a día, todo desde una interfaz centralizada y fácil de usar.

---

## ✅ Funcionalidades principales

### 🛍️ Gestión de Ventas
- Registro de nuevas ventas de forma rápida e intuitiva.
- Selección de productos disponibles en el catálogo.
- Cálculo automático de totales, subtotales e impuestos.
- Visualización del historial de ventas realizadas.

### 📦 Gestión de Productos
- Alta, modificación y eliminación de productos del catálogo.
- Asignación de precios, descripciones y categorías.
- Consulta del listado completo de productos disponibles.

### 👥 Gestión de Clientes
- Registro y administración de la base de clientes del negocio.
- Consulta del historial de compras por cliente.
- Datos de contacto y seguimiento de clientes.

### 🔐 Control de Acceso
- Sistema de inicio de sesión seguro para los usuarios del sistema.
- Acceso diferenciado según el rol del usuario (administrador, cajero, etc.).
- Protección de las operaciones sensibles del negocio.

### 📊 Reportes y Consultas
- Consulta de ventas por fecha o período.
- Resumen de las operaciones realizadas.
- Información de soporte para la toma de decisiones del negocio.

---

## 👤 ¿Para quién está pensado?

Este sistema está orientado a **pequeños y medianos negocios** que necesitan una herramienta ágil para:

- Cajeros y vendedores que registran ventas en el mostrador.
- Administradores que necesitan supervisar las operaciones comerciales.
- Dueños de negocio que desean tener control sobre su inventario y ventas.

---

## 🖥️ ¿Cómo se usa?

1. El usuario accede al sistema a través de un navegador web.
2. Inicia sesión con sus credenciales asignadas.
3. Desde el panel principal puede acceder a los módulos de ventas, productos y clientes.
4. Registra una nueva venta seleccionando productos y confirmando el cobro.
5. El sistema actualiza automáticamente los registros y el historial de operaciones.
